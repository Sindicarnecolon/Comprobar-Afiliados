# Comprobar Estado de Afiliados — Sindicato de la Carne (Colón)

Página web independiente y minimalista diseñada para que propietarios o responsables de comercios y establecimientos puedan verificar en pocos segundos si un afiliado se encuentra **ACTIVO** o **INACTIVO** ingresando únicamente su número de DNI.

## Características

- ⚡ **Comprobación rápida**: Solamente requiere ingresar el DNI del afiliado.
- 🔒 **Privacidad total**: No muestra nombres, apellidos, ni ningún otro dato personal sensible.
- 📆 **Vigencia determinista**: Modulo de interpretación de fechas robusto que respeta la vigencia del afiliado durante todo el día indicado en su vencimiento (`DD/MM/YYYY`).
- 📱 **Diseño adaptable**: Optimizada para uso desde dispositivos móviles (teclado numérico activo) y escritorios.
- 🌐 **Sin backend propio**: Funciona como una Web App estática alojada directamente en GitHub Pages.

## Guía de Publicación en GitHub Pages

1. Repositorio exclusivo de esta aplicación:
   `https://github.com/Sindicarnecolon/Comprobar-Afiliados.git`
2. En GitHub: ve a **Settings** → **Pages** → Source: **Deploy from a branch** → Branch: **`main` / `/(root)`** → **Save**.
3. La página estará disponible públicamente en la URL asignada por GitHub Pages.
